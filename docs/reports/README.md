# docs/reports 配置ルール

- 対象: 調査報告、作業報告、実施結果サマリ
- 配置: `docs/reports/YYYYMM/`
- 命名: `YYYYMMDD_テーマ名_報告.md`

例:
- `docs/reports/202604/20260422_v4参照統一_作業報告.md`
- `docs/reports/202604/20260423_A-D本番反映_調査分析_作業報告.md`
- `docs/reports/202605/20260524_YadOPERA_ConoHa移行完了_作業報告.md`
- `docs/reports/202605/20260524_Phase5完了後_本番公開状態_重大課題_発見記録.md`
- `docs/reports/202605/20260531_会話詳細404とDokploy_AutoDeploy_SG復旧_作業報告.md`
