**17 行 Save Successful**。投入法: **Mac 一括生成 → Dokploy 全貼付 → Save**（下記スクリプト）。

**Mac ターミナル**（`kurinobu@...MacBook`・SSH 内ではない）:

```bash
pip3 install -q python-dotenv 2>/dev/null; python3 <<'PY_EOF'
import secrets, subprocess, re, sys
from dotenv import dotenv_values

KEYS = [
    'BREVO_API_KEY','BREVO_SENDER_EMAIL','BREVO_SENDER_NAME',
    'FROM_EMAIL','FROM_NAME','ANTHROPIC_API_KEY','ANTHROPIC_MODEL',
    'USE_MOCK_API','API_TRAFFIC_PERCENTAGE',
    'CLAUDE_MAX_RETRIES','CLAUDE_RETRY_DELAY_BASE','CLAUDE_TIMEOUT_SECONDS',
]

def fetch_db_from_vps():
    cmd = (
        "ssh root@160.251.199.237 "
        "'C=$(docker ps --format \"{{.Names}}\" | grep motivationappstaging | head -1); "
        "docker exec \"$C\" printenv DATABASE_URL'"
    )
    return subprocess.check_output(cmd, shell=True, text=True, stderr=subprocess.STDOUT).strip()

def fetch_db_from_clipboard():
    clip = subprocess.check_output(["pbpaste"], text=True)
    for line in clip.splitlines():
        s = line.strip()
        if s.startswith("DATABASE_URL="):
            return s.split("=", 1)[1].strip()
    return None

db_url = None
try:
    db_url = fetch_db_from_vps()
except Exception:
    db_url = fetch_db_from_clipboard()
    if not db_url:
        print("ERROR: DATABASE_URL 取得失敗", file=sys.stderr)
        sys.exit(1)

prod_db = db_url.replace("/motivation_app", "/olovolo")
env = dotenv_values("/Users/kurinobu/motivation_app/.env")

print("")
print("========== ここから下を全部コピー（17行） ==========")
print(f"DATABASE_URL={prod_db}")
print(f"SECRET_KEY={secrets.token_urlsafe(48)}")
print("FLASK_ENV=production")
for k in KEYS:
    v = env.get(k)
    if v is not None:
        print(f"{k}={v}")
print("BASE_URL=https://olovolo.online")
print("PORT=5004")
print("========== ここまで ==========")
PY_EOF
```

**SSH 失敗時**: Dokploy `motivation-app-staging` Environment を **Cmd+A Cmd+C** してから同スクリプト再実行（クリップボード fallback）。
